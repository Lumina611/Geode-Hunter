# KEEP A STRAIGHT FACE! — Momo 表情原型

仅第一阶段：原创 SVG 少女角色与嘴角交互。无框架、无构建依赖、无游戏计时或规则，不部署网站。无需联网字体。

## 打开

在 Finder 的“文稿”中打开 keep-a-straight-face，双击 index.html，用 Safari 或 Chrome 查看。无需安装插件。

也可在终端运行：

```sh
cd keep-a-straight-face
python3 -m http.server 8765 --bind 127.0.0.1
```

浏览器访问 http://127.0.0.1:8765 。终端按 Control+C 停止服务。

## 试玩

拖动左右嘴角粉色小圆点，上拉微笑、下拉委屈。两侧可独立调整，松开后平滑回弹。嘴角位移限制在 SVG 坐标 -32 至 +34。表情按钮可短暂预览双侧表情。“恢复淡定”重置。

触屏使用同一套 Pointer Events 与指针捕获，取消手势、窗口失焦均重置。方向键 ↑ ↓ 可调整聚焦的嘴角，Home/Escape 重置，移开焦点后回弹。尊重减少动态效果偏好。

## 文件

- index.html：页面与手绘 SVG 角色。
- style.css：奶油色、粉色界面与响应式布局。
- script.js：二次贝塞尔嘴巴、五官联动、按帧指数平滑回弹。
