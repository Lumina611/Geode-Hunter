# Geode Hunter / 晶洞猎人 — V0.2

一款浏览器晶洞开石小游戏：从 25 颗未知原石中挑选，旋转观察，猜测内部类型，再支付虚拟矿币敲开。面向喜欢矿物、随机发现和轻松探索的人。**当前是完整可玩骨架，不是最终写实美术。**

## 最简单的启动方法（Mac）

1. 在仓库文件夹里双击 **启动晶洞猎人.command**，保持终端窗口开启。
2. 在浏览器打开 **http://127.0.0.1:8773/prototype/**。
3. 玩完在终端按 Control+C 停止。下载 ZIP 后若脚本不可执行，使用下面的终端方法。

也可打开终端，进入包含本 README 的目录，执行：

```sh
python3 -m http.server 8773 --bind 127.0.0.1
```

然后打开 [本机原型](http://127.0.0.1:8773/prototype/)。端口占用可换 8774，并同步修改地址。需要 Python 3（仅静态服务器）与支持 WebGL、ES Modules、import map 的近期浏览器。无需 npm、账号、网络服务或付费。**不能只双击 HTML**。localhost 仅在自己的电脑服务运行时可访问，不是公开 live link。

## 怎么玩

1. 在 5×5 工作台点击 01～25 中任意一颗，观察免费，随时可返回比较。
2. 拖动石头旋转，滚轮缩放；工具栏有旋转、缩放、补光与恢复视角。触摸采用单指旋转、双指缩放，实体触屏尚未验收。
3. 选择白色/透明、灰色/烟色、紫色、其他/特殊，确认后该颗猜测固定，再支付 **20** 矿币。
4. **直接点石头**或按敲击按钮四次。拖动不算敲击，空白处也不算；方向键/加减号观察，聚焦观察区后 Enter/空格敲击。
5. 揭晓名称、游戏稀有度和猜测结果，点击“领取”取得奖励，然后继续挑石。
6. 右上角可静音及中英文切换，切换不清空进度。收藏分本局与永久图鉴。
7. 余额不足 20 且仍有未开石头时结算；全部 25 颗完成则进入完成结算。重新开始有确认，恢复 100 矿币、换一批石头，永久图鉴保留。

| 数值 | 规则 |
| --- | --- |
| 初始矿币 | 100 |
| 每颗成本 | 20 |
| 成功开石 | +8 |
| 猜对大类 | +12 |
| 本局首次具体品种 | +10（独立于永久图鉴） |

只提供白晶细闪、透明长柱石英、烟晶、浅紫、深紫五种占位内部；“其他/特殊”暂没有对应结果，玩法说明已明确。所有稀有度仅为游戏标签。

## 固定结果、保存与中断

开局一次性按种子生成 25 颗石头的内部类型、外壳、造型种子和 1～2 条线索。观察、返回、支付与敲击都不抽新结果。已开原石有标记，可重新查看但不能重复付费/领奖。

支付后中途返回或刷新可继续；同一时间只允许一颗处于开石/待领取状态。第 4 次只是揭晓，领取时一次性结算奖励，避免重复领取或在已付款未揭晓时提前 Game Over。

本局使用 localStorage 保存“种子 + 操作日志”，刷新后重放合法操作恢复，不信任单独存储的矿币数字。永久图鉴单独保存；存储禁用时有提示并继续在内存中玩，损坏存档会提示并开始新局。存档只限同一浏览器与同一地址/端口；更换端口或浏览器会看到独立进度。不跨设备同步。它是本地游戏存档，不是防作弊服务器。

## 代码与素材替换

- `prototype/config.js`：所有重要数值、五种内部、五种外壳、观察文字、稀有度及配对素材配置。
- `prototype/game.mjs`：固定生成、猜测、支付、敲击、领奖、结算与存档重放，不依赖 DOM 或 Three.js。
- `prototype/app.js`：沿用单石版本的真实 Three.js 几何、旋转缩放、裂纹/半壳动画；同一渲染器生成外观缩略图。
- `prototype/ui.js`：页面切换、共享输入入口、声音、保存和收藏。
- `prototype/i18n.js`、`vocabulary.js`：双语词典；`sound.js`：本地合成声音，无麦克风/在线录音。
- `tests/game.test.mjs`：状态、经济、固定结果和结算测试。

[素材契约](docs/ASSET_CONTRACT.md) 说明如何按外壳+内部配对提供 GLB、PBR 贴图、二维微距图和图鉴图片。正式 GLB 尚未提供，不能声称已通过正式素材验收。

## 已验证与限制

六组自动化测试通过；真实浏览器已走观察返回、支付后刷新恢复、直接敲击、奖励、收藏、Game Over 和重开。完整测试与边界见 [V0.2 测试记录](docs/V02_TESTING.md)。

全部石头仍是现有程序模型的变体，外壳表皮/接缝、规则矿带、晶体透明折射和裂纹都偏占位；细闪与长柱有长度/密度变化，颜色分五类，不能与摄影级素材混淆。图鉴色标也是占位，可打开 3D 查看。触屏实机、跨浏览器、长期性能和扬声器听感仍待确认。
