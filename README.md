# Geode Hunter / 晶洞猎人

## 当前版本：第一阶段技术验证（2026-10-29）

**只包含一块原石和一对白水晶细闪半壳。** 旋转、缩放、四次敲击、逐渐裂纹、最终分离和重置。使用临时程序模型与材质，不是最终写实美术。没有 25 块原石、猜测计分、矿币、结算或收藏系统。

用户在本轮补充了完整 GDD 与美术规范，然后明确要求先限制为技术验证；完整玩法作为后续依据，见 [未来 GDD](docs/FUTURE_GDD_V1.md)。本轮早些时候尝试的整批/经济草稿已存入工作区 work，未接入此页面、未作为已完成功能提交。

## 如何运行

下载或克隆仓库，在终端进入包含本 README 的目录，然后执行：

```sh
python3 -m http.server 8772 --bind 127.0.0.1
```

打开 [http://127.0.0.1:8772/prototype/](http://127.0.0.1:8772/prototype/) 。Control+C 停止。端口被占用可改为 8773，并更改浏览器地址。

**此版必须通过 HTTP 服务打开，不能只双击 HTML。** 为准备 GLB 替换，本版采用本地 ES Modules 与 import map，全部依赖随包提供；运行不需要网络、npm、账号或付费服务。需 Python 3（仅作静态服务器）和支持 WebGL / ES Modules / import map 的近期浏览器。不需要 uv 或 Python 库。

## 试玩

- 鼠标拖动可水平/垂直自由旋转，看正面、背面、侧面、顶部和底部；滚轮缩放。
- 按钮提供旋转/缩放替代；聚焦观察区后方向键旋转，加减号缩放。
- 前三次敲击逐渐增加裂纹，第四次两半分离，露出细闪白晶几何。
- 敲击后短暂锁定按钮，避免连续输入跳过阶段；揭晓后不再接受第五次敲击。
- 开石后仍可旋转与缩放。随时“重新开始”清除裂纹/次数，关闭补光并恢复同一颗原石。
- 触摸代码已保留，实体触屏与双指操作尚未本轮验证，桌面优先。

## 当前实现与真实差距

真正的 Three.js 3D 几何；不是图片假旋转。当前模型有凹凸外皮、浅色矿带、1,800 个短晶实例和双半壳。裂纹为预制程序线段，开石为状态驱动分离，不是物理破碎。

与摄影级参考图仍有明显差距：轮廓和矿带偏规则；颗粒纹理、裂纹厚度、真实石英透明折射、晶体生长方向和微距细节仍是占位效果。无正式 GLB、扫描材质或宏观摄影素材。静态参考图不代表实际 3D 品质。

## 正式素材替换

`prototype/config.js` 集中定义敲击次数、种子、正式模型 URL、节点名、贴图与细节图片路径。

- `app.js`：程序模型、渲染、手势和资产加载接口。
- `ui.js`：四次敲击与重置；不关心具体模型来自程序还是 GLB。
- `vendor/GLTFLoader.js`：已随包提供，加载本地 GLB / glTF；缺少或无效节点回退占位模型。
- `config.js` 的 detailImage 可补充正式二维微距图，界面明确标为二维图，不冒充可旋转模型。

交付正式资产时遵守 [模型替换契约](docs/ASSET_CONTRACT.md)。GLB 入口有实现，但尚未用用户正式模型验收，不能写“正式素材已验证”。
