# Geode Hunter / 晶洞猎人

**Assignment 3: An interactive experience — 阶段性进度提交，2026-10-29。**

本轮是选题调整与 3D 效果验证，**不是最终软件或最终课程提交**。原方向由作者描述为社交类产品；现在以个人对水晶的兴趣为出发点，探索“观察一颗原石，再揭晓内部晶簇”的互动。仓库早期可核实提交是 Momo 表情原型，二者不应混为一谈，详见 [PROCESS](PROCESS.md)。

## 面向谁、做什么

面向对水晶、矿物外观或探索类互动感兴趣的初次体验者。这是设计假设，尚未经用户调研验证。

拖动或触摸旋转原石，滚轮或双指缩放；阅读观察提示，可选一个猜想，点击“敲开原石”看到紫色晶簇，再转动欣赏或重新探索。反馈包括角度/缩放、阶段文案、双瓣分离动画和猜想对照。当前仅一颗固定紫水晶演示标本，不是随机抽奖或矿物鉴定工具。

## 如何运行（浏览器项目）

下载 ZIP 并解压，保留文件夹结构。从终端进入解压后的仓库根目录（有本 README 的目录），运行：

```sh
python3 -m http.server 8772 --bind 127.0.0.1
```

在同一台电脑的浏览器打开 **http://127.0.0.1:8772/prototype/**。需要 Python 3 启动静态服务，应用本身不使用 Python 库、模型或 API；不需 uv、npm、付费账号或远程资源。用 Control+C 停止。端口被占用时改为 8773，并同步更换浏览器地址。也可用 VS Code 的静态服务器扩展服务此目录。

`prototype/index.html` 不使用 fetch 或模块导入，设计上可直接双击离线打开；本轮浏览器工具只验收了本机 HTTP 方式，未将 file:// 方式记为已验证。Three.js 0.160.1 已随仓库提供，需支持 WebGL 的近期浏览器。

未发布托管演示；上述 127.0.0.1 地址不是他人可访问的在线链接。

## 控制与普通中断

- 鼠标/单指拖动：水平和垂直自由旋转；滚轮/双指：有上下限的缩放。
- 方向按钮及放大/缩小按钮可替代手势。聚焦观察区后，方向键旋转，`+` / `-` 缩放。
- 线索、侧向补光和自动旋转辅助观察；猜想可不选。
- 开石后禁用重复开石及猜想；重置恢复标本、猜想、线索序号、补光和自动旋转。
- 指针取消/捕获丢失、失焦时清空手势；WebGL 初始化失败显示原因和换浏览器提示，上下文丢失提示刷新。部分异常分支尚未在真实浏览器中复现，见测试记录。
