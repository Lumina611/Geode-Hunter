# Geode Hunter / 晶洞猎人 — V0.3

从同一张三维开石工作台的 25 颗原石里挑选，旋转观察、猜测、支付虚拟矿币，敲四次揭晓并收藏。面向喜欢天然矿物和轻松发现体验的人。**这是可玩原型；正式写实美术尚未完成。**

## 启动（Mac）

双击本文件夹的 **启动晶洞猎人.command**，保持终端开启，再打开 [http://127.0.0.1:8773/prototype/](http://127.0.0.1:8773/prototype/)。玩完按 Control+C 停止。

也可在新终端进入本 README 所在目录后运行：

```sh
python3 -m http.server 8773 --bind 127.0.0.1
```

端口被占用可换 8776，地址也要改。需要 Python 3 作静态服务器、支持 WebGL / ES Modules / import map 的近期浏览器；无需 npm、账号、网络服务或付费。不能只双击 HTML。localhost 不是公开 live link，必须先运行服务。

## V0.3 的改变

- **同一真实三维场景**摆放 25 个原石组，共用透视相机、连续程序木纹桌面、统一光照和投影阴影。每个原石组由配对半壳外表组成；不是 25 张图片、25 个画布或去边框卡片。
- 位置接近 5×5，开局固定错位、尺度与朝向。可点石头本体（射线拾取），也可用浮动编号；悬停显示编号，选中后出现光圈与底栏，点「拿起观察」后镜头靠近，返回退回原桌面。过渡期间短暂锁定选择，避免点到移动中的目标。
- 已开石头从桌面隐藏，留下编号/空位标记，可回看但不能重复支付或领奖。
- 数据扩展为 **14 个外观类别：12 个真实矿物外观参考 + 2 个明确虚构的幻想款**，不是 14 个独立矿物种。不同晶体使用细闪、长柱、粗短柱、矿带、菱面体、犬牙状、圆润集合体、针片、板状、共生等程序形态与密度。
- 天青石仅作未来产区资料，不生成在当前初始批次。约 5% 的批次会预先固定加入一颗幻想款，每批最多一颗，不保证出现。
- 收藏馆使用各自 3D 标本的真实渲染图和锁定剪影；可进入 3D 详情旋转/缩放，显示矿物、形态、游戏稀有度与说明。四类已接入参考图重建 GLB，其余为程序占位，**不宣称摄影级收藏效果**。
- 敲击加入短暂衰减震动、渐长裂纹与小量有重力的石屑尘点；沿用本地合成敲击/碎裂声音，无真实破碎物理。

## 怎么玩

1. 点桌面上的原石或编号选中，再点底栏「拿起观察」；观察免费。滚轮可微调工作台视距。
2. 近看时拖动旋转、滚轮缩放，工具栏可补光、转向、恢复视角；方向键/加减号也可用。
3. 从白色/透明、灰色/烟色、紫色、其他/特殊里确认一次猜测，再支付 **20** 矿币。
4. 直接点石头或按敲击按钮四次；拖动和点空白不算。聚焦观察区后 Enter/空格可敲击。
5. 揭晓后领取一次奖励，继续挑石。永久图鉴独立保存。右上角可静音及中英文切换。

| 规则 | 数值 |
| --- | --- |
| 初始 | 100 矿币 |
| 开石成本 | 20 |
| 成功开石 | +8 |
| 猜对大类 | +12 |
| 本局首次具体品种 | +10（不看永久图鉴是否已有） |

领取后余额不足 20 且仍有未开原石时 Game Over；25 颗全部开启则 Complete。已支付原石可以先敲完并领奖，不会因付款后低余额提前结束。重新开始有确认，恢复 100、生成新批次，保留永久图鉴。

## 固定结果与旧存档

开局按种子确定内部、外壳、线索、造型和桌面位置；观察/返回/支付/敲击不再抽取结果。存档使用种子和合法操作日志重放；永久收藏单独保存。每次只允许一颗正在敲击或待领奖的原石，可中途返回或刷新恢复。

V0.3 会读取并保留 V0.2 的本局和图鉴：旧局继续用原五类生成规则，避免重抽结果；**新开一局才使用 14 类 V0.3 数据**。旧 localStorage 键不删除，V0.3 用新键保存。正式入口实际迁移保留了 16 颗已开、8 矿币的旧局。

进度只属于同一浏览器、地址和端口，不跨设备同步；建议每局只开一个标签。存储不可用时提示后继续内存游玩；损坏记录有提示。它不是防作弊服务器。批次的摩洛哥/墨西哥标记是游戏主题，不能当作标本真实来源保证。

## 代码与资源

- `game.mjs`：生成、固定位置、状态/经济、存档恢复。`legacy-v02-config.js` 保持原生成输入供迁移。
- `table.js`：一个工作台 Scene、一个透视相机、一个工作台画布、25 个原石组，射线拾取、编号、投影和镜头过渡。观察继续复用 `app.js`；不是每颗开一个渲染器。
- `config.js`：14 类名字、矿物、形态、颜色、稀有度、幻想标记、线索建议类型与独立美术路径。实际线索从外壳家族生成，不是鉴定规则。
- `assets.js`：桌面外壳和观察双半壳共用的配对资源解析，支持同壳/品种及精确种子覆盖。
- `ui.js` / 双语词典 / `sound.js`：控制、图鉴、本地声音。

## 验证与当前差距

[此前 V0.3 浏览器记录](docs/V03_TESTING.md) 包括全部 25 位置选中、射线选石、返回不变、刷新恢复、奖励、Game Over、永久图鉴重开保留、旧局迁移和竖屏检查。

桌面与标本仍是程序几何、程序木纹/颗粒、近似晶形；矿带规则、接缝、石英折射、真实生长方向和细节尚未达到摄影级。已接入四类程序重建 GLB 并实际验证本地加载；尚未提供实物扫描或正式摄影级资产。实体触屏、长时间性能及扬声器听感未验收。幻想两类明确标为虚构。

本轮增补后共 19 组自动测试通过；详细的模型、浏览器和缺失文件回退记录见 [参考模型说明](docs/REFERENCE_MODELS.md)。开发检查（正常游玩不需要 Node）：

```sh
node --test tests/*.test.mjs
```

`tests/visual.html` 是不读取或改写存档的 14 类程序形态验收页，不代表玩家解锁，也不是真人试用。

原 Momo、转向、单石、V0.2 的真实过程继续保留在 [PROCESS](PROCESS.md) 和 Git 历史；[Momo 原报告](archive/Momo-v1/README.md) 未删除。仍需至少一位其他人无讲解试玩并据此迭代。尚未提交 Canvas，未部署网站；每次通过 GitHub Desktop 保存。
