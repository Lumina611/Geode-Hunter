# 白水晶细闪 · 单品种内部改版

2026-10-29。作者要求以参考 A 的舒适度为方向：浅色连续内壁、局部短晶簇、自然空腔，修正均匀疙瘩、黑缝、放射纹和偏黄的重复矿带。只改白晶，不推进其他矿物。

## 实际模型与参数

旧版每半壳 1,700 个独立小晶体，Fibonacci 半球均匀分布，内壁为极坐标网格；顶点中心亮度系数 0.20，外缘五段颜色叠加重复正弦纹。旧版完整保留为 `white-druse-study-v1.glb`。

新版为 `white-druse-study-v2.glb`，不是把参考图贴在平面上：

| 项目 | 新版实际实现 |
| --- | --- |
| 连续底层 | 抖动笛卡尔网格映射到不规则空腔，每半壳 16,562 个相连三角面，微小几何起伏；没有中心扇形汇聚 |
| 独立短晶体 | 每半壳 78 个，分成 42 / 27 / 9 三组，尺度、位置、朝向和非等宽六棱面各异；较大平缓区域保留 |
| 细闪 | 连续表面的微棱面几何、非放射细晶法线及粗糙度贴图；固定摄影棚反射随真实旋转移动，没有随机闪星 |
| 晶体 | 六棱柱短体、分段终端棱面，石英近似 IOR 1.46、部分透射和清漆反射；没有统一满洞尖锥 |
| 矿带 | 平滑轮廓拟合后内缩约 0.18 单位，取消五道重复环纹，浅白至中性灰过渡；局部实际厚度受原壳轮廓影响 |
| 配对外壳 | 原版 Closed_front / Closed_back / 两个 Outer_shell 的位置、法线、UV 字节完全保留 |
| 资源体积 | 新 GLB 约 7.5 MiB，六张嵌入纹理；可用同样 Closed / Open_Left / Open_Right 节点约定替换 |

只在白晶打开后启用单独的柔和补光和小面积反光板环境。完整原石、工作台和其他品种保留原灯光。图鉴缩略图按品种独立选择灯光，避免看过白晶后把补光带到其他标本。曝光仍为 1，未靠整体增亮替代几何修正。

复现生成：仓库根目录执行 `node tools/build-white-druse-v2.mjs`。使用仓库内 Three.js 和 Node 内置模块；仅生成 v2 白晶 GLB、三张白晶贴图及其 manifest。原版及其他模型不重建。

## 实际验收

- `node --test tests/*.test.mjs`：19 项通过。新增检查外壳全部属性不变、四个原版模型 SHA-256 不变、内壁连通/无内孔/无高连接度中心扇面、白晶灯光能恢复其他品种原设置；原游戏固定结果、经济、重开、迁移继续回归。
- 浏览器拖动：X 从 6.9° 到 16.0°，Y 从 -169.0° 到 -141.5°，距离保持 5.60。局部晶面反光移动，截图保存。滚轮缩放和固定镜头恢复均实际操作。
- 原游戏渲染器验收页：读取可见 stage 的资源标记为 v2；直接点击石头本体四次，计数 1→2→3→4，裂纹/双半壳揭晓正常；切换深紫仍加载原 v1。
- 主游戏刷新后保留作者第 3 批、78 矿币和待完成原石，再由永久图鉴免费预览白晶，资源标记为 v2。未支付、领奖或重开作者的局。正常页面无 warn/error。

这是助手技术检查，不是另一位参与者试玩。本轮未在浏览器重新完整通关全部 25 颗或重走 Game Over；相关自动回归与之前记录分开保留。未新测实体触屏或低端设备。

## 仍需评审的差距

它仍是程序三维工作样，不等同参考摄影：连续底层有细三角面质感，短晶簇在远景偏小、通透度和不规则生长仍近似；部分角度白色反光较强，外壳原来的轮廓和局部矿带厚度仍不够天然。透射是实时 PBR 近似，没有真实晶体内部包裹体、多次折射或扫描细节。本轮没有制作新的 AI 静态概念图，也没有修改其他品种来凑数量；下一矿物须等作者确认方向。
