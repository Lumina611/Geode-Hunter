# 方向与方案 v0.2 / 进度版

## 背景与问题

作者喜欢水晶，希望用个人兴趣驱动作业。设计问题：如何用小型浏览器互动，让人从观察外皮、形成猜想到发现内部晶体？这是设计探索，没有用户研究证明的市场痛点。

## 对象、场景与定位

面向对水晶、矿物造型或探索互动好奇的初次体验者，在电脑浏览器做 1–3 分钟的观察演示。以上是待验证假设。移动触摸是设计目标，尚未完成实体设备验证。

定位：静谧的单人晶洞探索原型。强调探索、猜测、揭晓与形态欣赏。一颗固定紫水晶标本；无账号、个人数据采集、交易、付费、经营或社交；不作鉴定、治疗或投资承诺。

## 核心流程

| 阶段 | 输入 | 响应 | 反馈与下一步 |
| --- | --- | --- | --- |
| 进入 | 打开页面 | 创建固定标本与场景 | 等待观察、操作提示 |
| 观察 | 拖动/缩放/线索/补光 | 改变旋转、相机、灯光或文案 | 遮挡反光变化、角度缩放数值 |
| 猜想 | 下拉选择，可不选 | 保存当前猜想 | 不评分，不要求猜对 |
| 揭晓 | 点击开石 | opened=true，双瓣插值分离 | 晶簇和猜想反馈，禁用重复开石 |
| 欣赏 | 继续旋转/缩放 | 展示晶尖、矿带与背面 | 可重新探索 |
| 重置 | 重新探索 | 恢复标本、视角、线索、猜想、开关 | 可再次开石，同一标本 |

## 页面设计

深绿背景、浅绿动作与紫色晶簇。桌面左侧介绍、中间独立 3D 区、右侧手记，底部主要动作。窄屏顺序布局和底部动作条有代码实现，移动实测待完成。方向与缩放按钮提供手势替代。

## 技术方案

原生 HTML/CSS/JavaScript + 本地 Three.js 0.160.1 MIT；无 React、后端、API 或构建步骤。种子 1487 固定生成。外壳/内壁/矿带用 BufferGeometry，六棱晶体用 InstancedMesh；不是图片旋转。开石为预建双瓣分离，不是物理破碎或真实光学折射。相机 z 限制 4.5–15；动画按时间平滑插值；Pointer Events 处理手势。

解释代码：app.js 的 crack() 将 opened 置为 true，更新猜想、文字和按钮；animate() 中 progress 从 0 到 1，两半位置为 ±progress×1.43，旋转同时变化，renderer.render 呈现。因此输入改变三维程序状态，不只是装饰文案。作者还需自己核对并能解释这一段。
