# 本轮 Phase 1 验证 — 2026-10-29

测试对象：当前白晶单石版本。先前紫晶、猜想或收藏的测试记录是历史，不代表本阶段功能。

## 实际执行

- JavaScript 语法检查 app.js / ui.js：通过。
- 本机 HTTP 页面：真实 WebGL 原石可见，非渲染器替身。
- 鼠标拖动：读数从 340° 到 56°，模型跟随转动。
- 滚轮缩放：100% 到 105%（读数取插值过程中），画面变化。
- 四次敲击：逐次读到“已敲击 1/2/3 次”，第四次为白晶揭晓。前 3 次不出现内部揭晓。
- 第四次之后按钮 isEnabled=false，不接受第五次敲击。
- 目视检查：白晶双半壳与矿带可见；裂纹 1 与裂纹 3 截图已保留。
- 揭晓后重置：恢复完整原石与第一次敲击。
- 第一次敲击后立即重置：恢复完整原石，清除待恢复按钮计时器，未被旧回调跳到揭晓。
- 干净浏览器页面读取 warn/error：空列表。本轮改用本地 ES Modules，不加载旧 three.min.js；旧标签的历史警告不当作本版本日志。

## 未验证

实体触屏、双指捏合、Safari/Chrome 各版本、手机性能、减少动画系统偏好；用户正式 GLB/贴图、坏 GLB 回退、丢失 WebGL 上下文的真实分支。没有另一人的真人试玩。

## 视觉限制

占位外壳仍有程序感；晶体不具备摄影级透明折射，矿带偏规则、微距细节不足。裂纹是线段模拟、不是物理裂开。这些限制不因功能测试通过而消失。
