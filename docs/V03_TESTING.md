## 实测发现与修复

1. 浮动编号沿用普通按钮的按下位移，点击目标可能在松开前移位。固定锚点变换，使用指针捕获；保留键盘点击入口。
2. 镜头返回时编号仍在移动，连续点击偶发失配。过渡期间暂时禁用编号，稳定后恢复；完成后重新实测全部 25 个成功。
3. 从桌面切为手机宽度时，返回镜头仍使用旧终点，造成裁切。重新计算并更新动画终点；375px 下 25 编号均可见且六个前后排位置验证通过。
4. 原五品种测试写死种类数/150 矿币，扩展后不再适用；保留旧生成器回归，并增加按实际新品种数核算 V0.3 的测试，不把失败的旧预期当经济规则坏掉。

## 未验证与限制

没有正式摄影、扫描纹理或正式 GLB，因此它们的视觉质量、加载失败/重试、复杂材质、压缩扩展和长期内存仍需专项验收。当前实测是程序资源，阴影/纹理/晶形并非摄影级；三角锥、斜块等只近似习性。实体触屏双指、低端手机、跨浏览器、持续帧率、扬声器实际音色未验收。当前建议一局只用一个标签，不支持多标签并发合并。没有任何他人试玩或访谈数据。
