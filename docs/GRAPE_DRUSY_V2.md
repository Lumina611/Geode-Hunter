## 网上找到的真实依据

以下是标本持有者/展售者的现场资料与照片。本轮只链接参考，没有把其照片下载到游戏、用作贴图、输入图像生成器或公开再分发。

- [FossilEra，标本 #105118](https://www.fossilera.com/minerals/1-7-purple-botryoidal-druzy-grape-agate-indonesia)：实际在浏览器放大看了照片。圆润结核有尺寸和连生变化，局部覆有细小晶体，呈现柔和紫色及较浅的覆晶反光。该标本说明与照片来自苏拉威西，不是游戏摩洛哥/墨西哥主题批次的实物来源保证。
- [Khyber Mineral Company，ING01/02/04/05](https://www.khyberminerals.com/collections/50/)：多件标本描述球状集合体后期被细小石英晶体覆盖，部分区域较亮、部分仍较哑光。这支持“圆润主体 + 微晶皮”的两级材质，而非整颗光滑塑料球或随机闪星。
- [Mardani，标本 13452](https://www.mardanifineminerals.com/blog/2020/10/11/amethyst-13452/)：其标本使用葡萄状紫晶的命名；“grape agate / chalcedony”有商称和鉴定差异。游戏沿用原显示名和稳定 ID，主要矿物改为较宽泛的“石英类”，不将颜色和球状外观当成严格鉴定。
- [University of St Andrews，GE12275](https://collections.st-andrews.ac.uk/item/botryoidal-crust-of-chalcedony/1021090)：真实玉髓葡萄状壳层可呈白黄、半透明；不能推断所有葡萄状玉髓都必须是紫色且覆有可见晶面。本轮选的是作者指定的覆晶型外观。

另检索了网上三维素材：[TurboSquid 同题材模型](https://www.turbosquid.com/3d-models/3ds-max-botryoidal-chalcedony-druzy-quartz/831289) 是商业资源，未购买、下载或接入，也未确认允许作为原始资产放入课程公共仓库。本轮没有找到并取得许可明确、可以直接公开再分发的匹配扫描模型，故交付的是原创程序工作样。

## 模型实际做了什么

- 两半分别由 139 / 144 个不等尺度的椭球生长核构造，标量场与 marching tetrahedra 形成连生外皮；不是堆放同尺寸光滑球的旧实现。
- 连续主体为 74,448 / 78,652 三角面，使用插值梯度法线保持圆润；低饱和紫色变化与少量灰绿色过渡。中央保留空腔，分布仍是设计近似。
- 额外 3,261 / 3,409 个极小六棱石英几何，直接在真实主体三角面上按面积采样生长；尺寸随结核缩小，底部略埋入表皮，避免悬空。不是场景 Points、星形贴纸或计时闪烁。
- 主体使用细晶法线、粗糙度变化与轻微透射；覆晶继承主体颜色，减少固定白砂感，由晶面和固定摄影棚反光产生小高光。微晶近似 IOR 1.54，无自发光。
- 原来的 `Closed_front`、`Closed_back` 与双半壳外壳位置/法线/UV 字节保持。外壳纹理仍沿用当前项目；矿带只是较中性的程序过渡，不声称是天然扫描。
- 顶点合并索引后 GLB 为 22,553,808 字节，约 21.5 MiB。通过原有资源接口接入观察、图鉴与工作台闭壳；游戏规则、固定结果、权重、稀有度、猜测大类及旧存档机制未改。
- 打开的葡萄状晶洞复用白晶已经建立的柔和摄影棚，其他类型/闭壳回原灯光。白晶 V2 文件 SHA-256 仍为 `da0c7bc00b890b771e680d5091f89396ed3e49b75129f14ca196b02d5a0e422d`。

生成命令：`node tools/build-grape-drusy-v2.mjs`。使用仓库已有 Three.js 和 Node 内置模块，不新增运行依赖。不重写旧 v1 GLB 或白晶资产。

## 未完成与边界

当前比旧光滑球更有表皮与连生结构，但仍明显比方向图简化：空腔轮廓和矿带过于规则，主体可能偏圆/偏哑光，微晶反光在远景或一些角度不够清楚，尚无真实包裹体和精细生长纹。不是扫描资产，不宣称达到摄影级。

仍需作者评审疏密、颜色和表皮尺度；未完成其余全部晶洞的美术升级。本轮未重新浏览器通关25颗或重走Game Over，没有真人无讲解试玩或实体触屏/低端设备性能测试。模型体积和微晶数量需要后续优化与设备验证；已有玩法自动回归不能替代上述验证。
