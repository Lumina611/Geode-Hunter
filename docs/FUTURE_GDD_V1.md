# Geode Hunter GDD V1.0 — 后续开发依据，不是当前功能

来源：2026-10-29 用户提供的完整 GDD 与素材规范。最新优先级：当前只做一颗不规则 3D 原石、旋转缩放、四次敲击、白晶揭晓；不接入本文件中的整批或经济系统。

## 已确认完整玩法

- 桌面浏览器优先，后续触屏；HTML/CSS/JS/Three.js。安静、轻松、好奇、期待与发现，不做打工、签到、付费或复杂经营。
- 5×5 共 25 块外形/纹理不同的原石。批次生成时固定 ID、位置、外壳、内部品种、晶型、等级、线索及配对素材；重复观察不改变结果，不在开石时抽取。
- 观察免费，自由看前后左右上下和细节；局部线索有参考价值但不等于答案，不能所有紫晶外壳发紫。
- 主要类型猜测：白/透明、灰/烟、紫、其他特殊；每颗仅确认一次，确认前可继续观察；确认后再决定支付开石。
- 四次敲击：细裂纹 → 裂纹扩大/碎屑 → 贯穿松动 → 双半壳揭晓。不做高复杂度物理引擎。
- 初始 100 矿币；每次 20；开石 +8、猜对主要类型 +12、本局首次外观 +10。新品种奖励按局重置，与永久图鉴分离。
- 矿币不足 20 且有未开原石则 Game Over；全开 25 则 Complete。结算开石数、正确数/率、种类、最稀有、称号。主动结束须确认。重新开始恢复 100、新批次、清本局记录，但保留永久图鉴。
- 图鉴按种类解锁名称、图片/3D、矿物、颜色、形态、可能产地、简短知识、游戏等级；未知为剪影，localStorage 持久化。真实矿物知识及产地需可靠来源，不给程序标本编造真实产地。
- 五种基础：细闪白晶、透明长柱、烟晶、浅紫、深紫。更多真实矿物及少量幻想隐藏款在后期，不保证每批有隐藏款。
- 声音：克制的拿起/敲击/细裂/揭晓/结算，默认不强播，不用老虎机与赌场风格。

## 美术与资产

摄影级天然矿物方向，炭黑、暖棕、灰、石灰岩米色、低饱和紫与自然白晶；柔和侧光和接触阴影，无普通晶体魔法光。统一简约无衬线字体与白灰控件（聊天 2 最后确认）。

真实不规则石壳、成对半壳、自然内壁厚度和矿带、变化的晶体大小与生长方向，避免塑料感、完美对称、重复尖锥、钻石镶嵌感和错误配壳。一个 3D 模型负责所有角度，不用不同石头照片拼接。推荐正式 GLB/glTF + 高分辨率 PBR 贴图，细节图为独立真实二维素材。

## 阶段计划

1. 当前：一块原石、白晶、四次敲击与真实浏览器验证。
2. 验证后：五种基础晶洞，确认外部与内部一致。
3. 再做：25 原石、固定结果、猜测、矿币与完整结算。
4. 后续：永久图鉴、其他矿物、稀有与幻想款。

每阶段保留真实截图、过程和 Desktop 提交。未开发内容不标完成，旧《假装正常人》报告和文件保留。
